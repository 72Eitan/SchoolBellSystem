## דרך העבודה שסוכמה
- תכנון קודם, ואז אישור. המשתמש אישר לבצע כל מה שנדרש **בתוך** `D:\Projects\SchoolBellSystem` בלבד. לא לגעת בתיקיות אחרות (גיבויים).
- כל תשובה **בעברית**.
- בסוף כל סבב: להעלות את הגרסה ב-`SERVER_VERSION` (web_server.py) וב-`CLIENT_VERSION` (index.html), לעדכן את PROJECT_SUMMARY.md ואת מסמך התוכנית, ולתת תיאור קצר ל-`backup_git.bat`.
- בדיקות: על עותק בסביבת בדיקה (API, דפדפן, והמנוע עם SDL dummy), ואז בדיקה של המשתמש על Windows.
- מרכז הבקרה רץ ב-https://etratzon.pythonanywhere.com. עדכון שלו: `dist\control_center_upload.zip` ← Files ← `unzip -o` בקונסולת Bash ← Reload.

## מה פתוח, לפי הסדר
1. **אצל המשתמש:** להעלות את `dist\control_center_upload.zip` ל-PythonAnywhere ולבדוק את לוח הצפייה בטלפון. (ייתכן שכבר בוצע - לשאול.)
2. **שלב 1ב סבב ב' חלק 2:** כפתורי עריכה באפליקציה למורשה המחובר (רמזור, השבתת אירוע להיום, שינוי שעה, יום ללא צלצולים, צלצול ידני). הבקשה נשמרת באתר, המחשב אוסף ומבצע דרך השרת המקומי (עם Undo ולוג בשם המורשה), ומאשר. לבדוק שהמורשה עדיין מורשה גם בצד המחשב.
3. **שלב 1, שנשאר:** הצעת חופשות לפי לוח השנה העברי ומגזר; לוח מיוחד לתאריך (יום קצר); כפתורי חירום ידניים; טופס "שלח הודעה ליוצר"; בורר עוצמה ראשי (טרם הוחלט); הקשחת רישיון; ספריית ~20 צלצולים; מתקין EXE עם Python 3.8; עדכון מרחוק ראשון; בדיקה על Windows 7.
4. **שלב 2:** עיצוב חדש לפי הדוגמאות במפרט, אחידות בין כל החלונות, אתר ומדריכים (בתיקיות `website/` ו-`guides/`).
5. **שלבים 3–4:** הודעה קולית, חיתוך שירים, כריזה, שני אזורים, התרעות ארציות, סוכנים, שפות, תוסף מסכים.

- צפייה: קישור ו-QR של בית הספר, בלי התחברות, ניתן להחלפה.
